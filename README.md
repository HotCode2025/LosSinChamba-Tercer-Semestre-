# Repositorio de Material de Estudio y Prácticas

Este repositorio contiene los recursos, apuntes y proyectos de las asignaturas de programación y bases de datos. Está diseñado para que los alumnos puedan seguir el progreso de las clases, descargar ejemplos de código, material de lectura y repasar los conceptos fundamentales.

## 🚀 Cómo usar este repositorio
1. Clona el repositorio en tu equipo local: `git clone [URL_DEL_REPOSITORIO]`
2. Asegúrate de tener instalado **Python**, **Node.js** (para JS), el **JDK de Java** y **PostgreSQL**.
3. Sigue las instrucciones de los videos de la plataforma para levantar los entornos virtuales.
4. Para los módulos de diseño y manipulación del DOM, puedes abrir los archivos HTML directamente en cualquier navegador web. Recuerda compilar tus archivos `.scss` a `.css` si estás utilizando **SASS**.
5. Configura tus credenciales de base de datos en los scripts correspondientes antes de ejecutar las prácticas de acceso a datos.
