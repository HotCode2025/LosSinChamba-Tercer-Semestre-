♛ Problema de las N Reinas

Algoritmos de Backtracking aplicados al ajedrez

¿En qué consiste el problema?

El Problema de las N Reinas consiste en colocar N reinas en un tablero de ajedrez de N × N de tal manera que ninguna reina pueda atacar a otra. Es decir, no pueden compartir la misma fila, columna ni diagonal.

Para resolverlo se utiliza la técnica de Backtracking: se van colocando reinas columna por columna y, si se detecta un conflicto, se retrocede y se prueba otra posición.

⚠️ El valor de N debe ser mayor o igual a 8.
